# 테스트 명세 — 시흥 하루이음

[문서 안내](../../README.md#문서-분류-기준)

## 검증 전략

[tests/](../../tests/)의 단위·모의 연동 검사와 프로덕션 HTTP 검사, 브라우저 핵심 흐름으로 검증한다. 실행·DB 분리는 [README](../../README.md#테스트), 완료 기준은 [요구사항](../01-func/01-requirements.md#완료-기준)을 따른다.

## 화면 검증

1365px·390px에서 탐색·지도·편집·내 여행·도우미·날씨·마이·모달·하단 메뉴의 가로 넘침과 조작을 확인한다.

## API·외부 연동 검증

세션·CSRF·입력 검증·소유권·리비전 충돌·기록/사진 보호·행사 날짜 보호·요청 한도를 검사한다. NAVER 연동은 요청 계약과 성공·오류·거부·키 미설정 응답을 모의 검증한다.

## 최신 판정

2026-11-20(Asia/Seoul), Windows에서 지도 상단의 예시 날씨와 공용 날씨 아이콘을 반영한 뒤 단위(36개)·타입·프로덕션 빌드를 통과했다. 서식은 Git 체크아웃의 CRLF를 허용하는 `--end-of-line auto`로 통과했다. 기본 서식 검사는 기존 파일의 CRLF를 경고한다. 기존 경기도 지도 화면은 사용자가 정상 동작을 확인했으며 자동 브라우저의 로컬 접속은 시간 초과로 완료하지 못했다. 이번 날씨 배치는 정적 렌더로 확인했으며 실화면은 재검증하지 않았다. 아래 지도 외 사진·HTTP·서버·배포 결과는 2026-11-17의 마지막 검증 결과이며 이번에 재실행하지 않았다.

| 검사 | 결과·범위 |
| --- | --- |
| 단위·모의 연동 36개 | 모두 통과했다. 새 검사 2개는 31개 시·군 경계·식별자·좌표와 관광지 대응, 시흥 자료의 다른 도시 노출 방지·기존 담기 상태 반영을 확인한다. 기존 세션·소유권·리비전·AI·이미지·날씨 검사도 통과했다. 경계 검사는 운영체제별 경로 구분자를 사용하도록 보완했다. |
| 서식·타입·빌드 | 타입 검사와 Next.js 프로덕션 빌드, CRLF를 허용한 전체 서식 검사를 통과했다. |
| 지도 날씨 표시 | 정적 렌더에서 기본 해 아이콘·10°C·예시 안내, 아이콘 아래 기온과 지도 아래 북쪽 표시의 순서, 6종 아이콘 렌더를 확인했다. 도시 선택 안내 문구를 제거한 뒤에도 날씨와 북쪽 표시가 남아 있는지 확인했다. 비·-3°C와 실시간 구분 값을 직접 전달했을 때 예시 표기가 사라지는 것을 확인했다. 실제 날씨 API는 지도 표시와 연결하지 않았다. |
| 경기도 경계 데이터 | 고정한 원본 SHA-256, 31개 시·군 병합과 공유 경계 정합성을 생성 단계에서 확인했다. 브라우저는 생성된 정적 SVG 데이터를 사용한다. |
| 경기도 화면·조작 | 사용자가 기본 화면의 정상 동작을 확인했다. 자동 브라우저의 로컬 접속은 시간 초과였으며 새 레이아웃의 1365px·390px, 키보드·초점·상세·담기·탭 복귀는 자동 실화면으로 확인하지 못했다. 도시별 목록과 담기 상태는 정적 렌더 검사로 확인했다. |
| 관광 사진 | 공개 사진 18장의 640px WebP 응답이 모두 200이고 가로 크기가 640px 이하임을 확인했다. 합산 용량은 원본 7,617,584바이트에서 860,696바이트로 약 89% 줄었다. 재요청은 캐시 HIT였다. 데스크톱 배너·카드·상세와 390px 카드·지도 사진이 정상 로딩됐고, 모바일 가로 넘침과 브라우저 경고·오류가 없었다. 실제 표시 크기·픽셀 밀도에 따라 전송량은 달라진다. |
| 화면·조작 | 390px에서 취향 저장·추천 연결·추천 적용·장소 이동/제외·여행 저장·방문 기록·마이 집계·새로고침 복원을 확인했다. 날씨 카드의 여행 담기·지도 연결과 상세 모달의 사진 출처·Esc 닫기, 데모 도우미의 운영 정보 확인 불가 안내를 확인했다. 390px 마이와 1365px 탐색 지도에 가로 넘침이 없었고 브라우저 오류·경고 로그가 없었다. |
| 네이버 로그인 HTTP | 더미 로그인 키로 인증 URL·쿠키·Origin 차단·콜백 실패/취소·state 재사용 차단·로그아웃 후 이전 쿠키의 401을 확인했다. 콜백의 Referrer-Policy는 no-referrer다. 네이버 실제 로그인은 호출하지 않았다. |
| 프로덕션 HTTP 기본·확장 | 로컬 별도 DB에서 모두 통과했다. 세션·CSRF·소유권·추천·날씨·OpenAPI, 여행 편집·충돌·사진·기록 보호·키 미설정·행사 저장을 확인했다. |
| 배포 스크립트 | Python 모의 검사 6개와 컨테이너 배포 스크립트의 Bash 문법 검사를 통과했다. |
| 재시작 | 테스트 컨테이너 재시작 후 같은 쿠키로 저장한 여행을 다시 조회했다. |
| 서버·외부 공개 | Docker 자동 시작과 영속 볼륨을 구성했다. Apache 프록시 문법 검사를 통과하고 활성화했다. 외부 IP의 HTTP 홈과 세션 생성이 모두 200을 반환했다. 앱 컨테이너는 내부 포트에 바인딩한다. |
| 문서·패치 | 이번 변경의 문서 링크·분류 검사는 Windows 경로를 정규화한 보정 실행으로 통과했으며, 공백 오류 검사도 통과했다. 원본 검사기는 Windows에서 기존 문서까지 미등록으로 판정한다. |
| 운영 모니터링 | 2026-11-17 실제 NAVER Cloud 서버에 Prometheus·Grafana·Node Exporter·Blackbox Exporter를 설치했다. promtool·Blackbox 설정 검사, 수집 대상 5개 UP, HTTP 탐침 2개 성공, Grafana 인증·데이터 소스 연결·대시보드 6개 패널의 실제 데이터 반환을 확인했다. 3001·9090·9100·9115 포트는 루프백에만 바인딩하고 앱 컨테이너를 재시작하지 않았다. Bash 문법·대시보드 JSON·문서 링크·공백 검사를 통과했다. 호스트 재부팅·장기 보관·알림 전송은 검증하지 않았다. |
| CD | 2026-11-17 [Actions 실배포](https://github.com/navercloud-6/project/actions/runs/43994202468)를 통과했다. ACG·기동 재시도 검사 6개와 서식·타입·단위·빌드·HTTP 검증을 통과한 커밋을 서버에서 빌드·교체했다. 홈·세션 API는 200이며 여행·사진 데이터 해시가 배포 전후 일치했다. 백업 2개와 자동 롤백 동작을 확인했고 임시 SSH 규칙을 삭제해 기존 ACG 8개를 유지했다. |
| 미확인 | HTTPS·NAVER 실키·호스트 재부팅을 확인하지 않았다. 네이버 로그인 실계정·검수·운영 배포와 로그인 성공 후 브라우저 조작은 키 설정 후 확인해야 한다. ACG 정책은 사용자가 관리하며 별도로 감사하지 않았다. 이번 사진 최적화에서는 실제 배포 서버의 로딩 시간·320px·여행 표지·담은 여행 썸네일·브라우저 사진 업로드·전체 키보드 접근성 흐름·서버 재시작을 재검사하지 않았다. |
