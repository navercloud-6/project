## 검증 전략

[tests/](../../tests/)의 단위·모의 연동, 프로덕션 HTTP, 브라우저 핵심 흐름으로 검증한다. 실행 명령은 [README](../../README.md#테스트), 완료 기준은 [요구사항](../01-func/01-requirements.md#완료-기준)을 따른다.

- **API·외부 연동**: 세션·CSRF·소유권·리비전 충돌·기록/사진/행사 날짜 보호·요청 한도와 NAVER 모의 계약을 검사한다.
- **날씨**: 31개 시·군 좌표·5일 예보·같은 도시 추천, 지도 캐시·동시 요청·오류·시연 구분과 도시 전환 시 이전 자료 숨김·선택 콜백을 검사한다.

## 최신 판정

2026-11-21(Asia/Seoul), CLOVA 라벨 609곳을 반영하고 `main`의 음성 안내·맛집·옷차림 기능을 병합했다. 사용자 요청에 따라 전체 라벨링 완료·병합 후 테스트와 빌드는 재실행하지 않았다. 아래 기존 검증은 각 브랜치에서 마지막으로 실행한 결과이며, 병합 결과의 통합 통과 판정으로 합산하지 않는다.

| 병합 상태 | `origin/main`의 PR #17까지 반영하고 기술 구조·검증 문서의 충돌을 양쪽 기능을 보존해 정리했다. Git 충돌 표시와 차이의 공백 오류를 확인했다. |
