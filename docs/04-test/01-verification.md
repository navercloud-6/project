# 테스트 명세 — 경기 하루이음

[문서 안내](../../README.md#문서-분류-기준)

## 검증 전략

[tests/](../../tests/)의 단위·모의 연동, 프로덕션 HTTP, 브라우저 핵심 흐름으로 검증한다. 실행 명령은 [README](../../README.md#테스트), 완료 기준은 [요구사항](../01-func/01-requirements.md#완료-기준)을 따른다.

- **API·외부 연동**: 세션·CSRF·소유권·리비전 충돌·기록/사진/행사 날짜 보호·요청 한도와 NAVER 모의 계약을 검사한다.
- **날씨**: 31개 시·군 좌표·5일 예보·같은 도시 추천, 지도 캐시·동시 요청·오류·시연 구분과 도시 전환 시 이전 자료 숨김·선택 콜백을 검사한다.

## 화면 검증

1365px·390px에서 탐색·경기도 지도·편집·내 여행·도우미·날씨·프로필·모달·하단 메뉴의 가로 넘침과 조작을 확인한다. 참고 화면은 [데스크톱](../screenshots/desktop.jpg)·[모바일](../screenshots/mobile.jpg)이다.

## 최신 판정

2026-11-21(Asia/Seoul), Windows 로컬에서 자연어 검색 조건과 검색 중·완료 후 표시 개수를 수정하고 PostgreSQL·CLOVA 실키·브라우저에서 확인한 최신 결과다. 장소 상세를 포함한 나머지 화면 조작은 이번 실행에서 재검증하지 않았다.

| 검사 | 최신 결과 |
| --- | --- |
| 단위·모의 연동 | `.env.local`의 PostgreSQL 접속 정보를 사용하고 실제 AI 키를 비운 테스트 환경에서 65개 모두 통과했다. 자연어 지역·동행·활동의 동시 적용, `산책`·`안산시`의 산 테마 오인식 방지, 빈 후보의 외부 호출 차단과 미리보기·추천 개수 제한을 확인했다. 도구 인수·장소·중복·4곳 이상 추천 거절 검사도 통과했다. |
| 서식·타입·빌드·문서 | `format:check -- --end-of-line auto`, `typecheck`, `build`, Windows 경로를 정규화한 문서 검사와 `git diff --check`를 통과했다. 원본 문서 검사기의 Windows 경로 구분자 제약은 남아 있다. |
| 검색 범위·결과 브라우저 | 1365px·390px에서 `안양시에서 할머니와 산책`의 미리보기·최종 추천이 검증 시점 최신 라벨의 안양시 일치 장소 2곳만 표시했다. `안양시 산책`은 16곳 중 미리보기 3곳만 표시했다. 추천 중 검색어를 수원시로 바꿨을 때 이전 응답이 표시되지 않았고, 완료 후 검색어를 바꾸면 추천이 지워졌다. 가로 넘침은 없었다. 라벨 배치 작업으로 일치 수는 변경될 수 있다. |
| CLOVA 추천 실키·로컬 | `http://127.0.0.1:3000`에서 `안양시에서 할머니와 산책` 질의가 CLOVA Reranker·`HCX-005`를 거쳐 조건 일치 장소 2곳을 반환했다. 화면은 추천 수를 따로 표시하고 추가 연관 목록을 붙이지 않았다. |
| 검색 패널·작업 전환 브라우저 (이전 검증) | 1365px에서 검색 패널 높이 약 153px, 검색 도구 높이 44px와 원본 아이콘 로딩을 확인했다. 작업 전환은 지도 아래에 표시되고 여행 편집·장소 찾기로 왕복했다. 390px에서 기본 패널은 약 203px이며, 지역 선택·실행 버튼의 같은 줄 배치, 테마 가로 스크롤·즉시 검색·초기화와 페이지 가로 넘침 없음을 확인했다. |
| AI 검색·상세 브라우저 (이전 검증) | 1365px에서 목록 항목과 기존 카드가 같은 장소 상세 모달을 여는지 비교했다. 꽃재체험농원의 실제 사진 로딩과 광명업사이클아트센터의 사진 없음 안내가 같은 높이(230px)로 표시되는지 확인했다. 390px에서도 상세창이 화면 안에 들어가고 추천 목록은 3곳을 유지했다. |
| 날씨 프로덕션 HTTP | `tests/city-weather-http.mjs`로 수원·시흥·가평의 현재 날씨와 5일 예보가 실제 `live` 응답임을 확인했다. 기본 도시·10분 캐시·잘못된 ID·메타데이터·OpenAPI 검사도 통과했다. |
| 프로덕션 HTTP (이전 검증) | `tests/http.mjs`, `tests/extensions-http.mjs`, `tests/auth-http.mjs`를 테스트 PostgreSQL 서버에서 통과했다(실제 네이버 로그인 미호출). |
| 배포 스크립트 (이전 검증) | `tests/acg_test.py`, `tests/deploy_test.py`(6개)와 `deploy/deploy-container.sh` 문법 검사를 통과했다. |
| 운영 이관·모니터링 (이전 검증) | NCP Cloud DB for PostgreSQL 17.11 이관(데이터 SHA-256 일치), `223.130.161.104` 외부 응답 200, Prometheus 5개 대상 UP·Blackbox `probe_success=1`을 확인했다. |
| 데이터·화면·사진 (이전 검증) | TourAPI 609곳(시흥 20 + 30개 시·군 589, 사진 456장) 수집, 경계 SHA-256·31개 시·군 정합성, 사진 WebP 약 89% 절감, 390px·1365px 기본 조작을 확인했다. |
| 미확인 | AI 검색 외 통합 화면의 실제 브라우저 조작은 재검증하지 않았다. HTTPS, CLOVA 추천·Reranker 외 NAVER 실키(Maps·로그인 포함), 추천의 다중 질의 품질·지연·과금, 호스트 재부팅·DB 백업 복원, GitHub Actions CD의 PostgreSQL 서비스 컨테이너 실실행은 미확인이다. |

미확인 항목과 후속 조건은 [남은 작업과 리스크](../03-tech/01-architecture.md#남은-작업과-리스크)를 따른다.
