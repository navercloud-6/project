# 요구사항 — 경기 하루이음

[문서 안내](../../README.md#문서-분류-기준)

## 범위

- **현재 구현**: 경기도 31개 시·군 관광지 탐색, CLOVA 라벨·Reranker AI 검색·추천, 패스 구성, 방문 기록, 통합 안내(날씨·안전·옷차림·명소·맛집·음성·번역), 여행 편집·사진 일기·포스터 인식을 제공하는 Next.js MVP다.
- **제외 범위**: 결제·할인·제휴·가맹점·관리자 기능, Object Storage, 대규모 벡터 DB·임베딩은 제외한다.
- **확장 목표**: 대상 지역은 경기도로 한정하며, 영어 UI(후속 일본어·중국어)와 시·군 단위 추천 계약 연계는 후속 과제로 둔다.

## 데이터·시연 고지 정책

- [관광 데이터](../../data/places.json)와 `public/places/` 사진은 검토 전(`DRAFT`) 자료이며 운영·요금·예약·최적 동선·혜택을 보장하지 않는다.
- 목록·상세에 검토 전 상태, 원문 확인일(`checkedOn`), 공식 출처, 사진 저작자·라이선스·크롭 안내를 표시한다.

## 세션·개인정보·사용 제한

- **익명 세션**: 32바이트 무작위 `tourpass-session` 쿠키(`HttpOnly`, `SameSite=Lax`, `Path=/`, 30일)의 SHA-256 해시로 소유권을 구분하며 쿠키 삭제·만료 후 재접근할 수 없다.
- **네이버 로그인**: 로그인 시 익명 여행·기록·사진을 계정에 연결하고 세션을 교체한다(타 계정 전환 시 이전 안 함). 로그아웃은 현재 세션을 폐기하고 빈 익명 보관함으로 전환하며 계정 여행은 유지한다. 동일인 식별자 해시만 저장하고 프로필·토큰은 저장하지 않으며, OAuth `state`는 10분 이내 1회만 사용한다(키 미설정 시 비활성).

## 핵심 기능 요구사항

### 경기도 지역 선택 지도

- 2026-07-01 기준 경기도 28개 시·3개 군 SVG 경계를 표시하고(일반구 병합, 서울·인천 제외) 출처·기준일·가공 여부를 안내한다.
- 초기 미선택 상태에서 클릭·터치·키보드·동기화 목록으로 단일 시·군을 선택하고 `경기도 전체 보기`로 해제한다. 선택 시 `cityId` 일치 장소만 표시하며(없으면 `관광 정보 준비 중`) 담은 여행·기록·시흥 권역 필터는 바꾸지 않는다.
- 지도 상단에 선택 시·군(미선택 시 수원)의 현재 날씨를 6종 아이콘·로딩·오류·재시도·명시적 시연 모드로 표시하며 실패를 예시 기온으로 대체하지 않는다.

### 시·군별 관광 데이터 확장

- TourAPI 국문 관광지·문화시설을 수집해 기존 시흥 20곳과 ID를 유지하고 타 시·군은 유효 자료를 최대 20곳씩 추가한다.
- 법정동 코드·주소로 지도 식별자를 대조하고 일반구 병합·타 시도·좌표 누락·중복 제거와 확인일·콘텐츠 ID·갱신일 보존을 적용한다. 사진은 공공누리 제1유형만 허용하며 인증키는 로컬 환경 변수로만 읽는다.

### 탐색·추천·날씨

- 609곳 카탈로그는 CLOVA 배치로 실내·야외·테마·동행·여행 방식·핵심 검색어 라벨을 사전 저장하며 수동 보정은 재라벨링 시에도 유지한다.
- 자연어 검색의 시·군명은 지역 제약으로, 동행·장소 구분·테마·활동은 모두 충족 조건으로 적용한다(동의어 포함, `산책`을 `산`으로 미확장). 미리보기와 AI 후보는 같은 필터를 쓰며 결과 없을 때 범위를 임의로 넓히지 않는다.
- AI 추천은 1차 후보(최대 20곳)를 CLOVA Reranker로 선별한 뒤 CLOVA Studio가 최대 3곳 코스를 생성하고 서버가 ID·중복·개수·지역을 검증한다(Reranker 실패 시 1차 후보 폴백, 키 없을 때만 데모, 키 설정 후 오류는 실패 표시).
- 미리보기·추천은 각 최대 3곳을 표시하고 조건 변경 시 이전 추천 제거·지연 응답을 무시한다. 카탈로그는 카드·지도를 전환하며 네이버 지도 미설정·실패 시 경기도 SVG 지도로 폴백한다.
- 경기도 전체(수원 기준)·31개 시·군의 현재 날씨·5일 예보·활동 가이드·추천 장소와 규칙 기반 옷차림·준비물(AI 미호출, Open-Meteo 실패 시 데모 표시)을 제공한다. 지도·날씨·도우미는 선택 시·군을 공유하며 전환 중 이전 자료를 숨긴다.
- 여행 도우미는 선택 시·군의 안전 안내(기상청 발효 특보·최근 24시간 지진·주의 한마디) → 통합 안내 원고·음성(자동 생성·선준비) → 옷차림 → 추천 명소 → NAVER 검색 맛집(최대 5곳, 술집·타 지역 제외, 후기 확인 메뉴 최대 3개, 맛·가격·영업 미보장)을 표시한다. 안전·맛집 실패 시 해당 항목 없이 계속하며 기존 관광 안내·행사 등록 화면은 탭에서 제외한다(API·컴포넌트 유지).

### 여행 패스·방문 기록·프로필

- 중복 없는 1~8곳의 순서 변경·제외 후 이름(1~60자)·날짜(`YYYY-MM-DD`)로 저장하며 추천 적용 시 목록을 교체한다.
- 새로고침·재시작 후에도 여행을 유지하고 장소별 만족도(1~5점)·메모(최대 500자)·코스 지도를 제공한다.
- 프로필에서 저장 여행 수·기록 고유 장소 수, 브라우저 선호 지역·취향(최대 500자, 추천 기본값), 네이버 로그인·보관 정책을 제공한다.

### 도우미 확장

| 기능 | 요구사항 | 키 미설정 시 |
| --- | --- | --- |
| 관광 안내 | 관련 장소 최대 3곳을 근거로 전달하고 `sourceIds`를 검증한다. 운영·요금·예약·주차·휠체어는 AI 없이 공식 출처만 안내한다. | 자료 검색 결과를 표시한다. |
| 여행 수정 | `propose_itinerary`·`revision` 미리보기 후 적용한다. 충돌은 `409`, 기록·사진 보유 장소 삭제와 포스터 행사 날짜 변경은 차단한다. | N번째 제외·순서 반전·정확한 장소명 추가 데모를 제공한다. |
| 음성·번역 | 장소 음성과 장소·여행 번역을 제공한다(정적 장소 재사용, 개인 여행 미캐시). | 비활성 안내와 `503`을 반환한다. |
| 통합 안내 | 안전 안내→날씨·옷차림→명소 3곳→맛집 3곳 1분 원고와 `nara`(한)·`clara`(영, Papago) 음성을 제공한다. 안전·명소·맛집 이름·메뉴·끝인사(`즐거운 여행 되세요!`)는 서버가 그대로 결합하고, AI 생성부는 숫자·옷차림·계절·길이 위반 시 재요청·규칙 문장으로 대체한다. 도우미 한도를 공유하며 키 설정 후 AI 오류는 실패로 알린다. | Studio 미설정 시 규칙 원고, Voice 미설정 시 원고만 표시하며, Papago 미설정 시 영어는 비활성·`503`이다. |
| 사진·일기 | 2MB 이하 JPEG·PNG·WebP를 검증·회전·1600px JPEG 재인코딩한다. 일기 초안은 메모 저장 시 확정한다. | 사진 저장만 가능하며 일기는 `503`을 반환한다. |
| 포스터 | OCR·Studio로 행사명·날짜·장소 초안을 만들고(모호한 날짜 공란) 카탈로그 장소 선택 후 `event.origin='poster'`로 저장한다. | 직접 입력·저장만 가능하며 인식은 `503`을 반환한다. |
