# 요구사항 — 경기 하루이음

[문서 안내](../../README.md#문서-분류-기준)

## 범위

### 현재 구현

경기도 31개 시·군의 관광지 탐색과 AI 여행 추천·패스 구성·방문 기록을 제공하는 Next.js 풀스택 MVP다.

- 시·군별 관광지 탐색, 여행 추천·패스 구성, 방문 기록, 관광 안내·여행 편집, 번역·음성·포스터 인식, 시흥권 날씨를 제공한다.
- 결제·할인·제휴·상점 인증, 관리자·가맹점 기능, Object Storage, 대규모 벡터 DB·임베딩·Reranker는 제외한다.

### 확장 목표

관광 대상 지역은 경기도로 한정한다. 해외 관광객을 대상으로 영어를 우선 지원하고, 일본어·중국어는 이후 확장한다. 경기도 지도에 연결할 다른 시·군의 관광 데이터를 아래 기준으로 확장하며, 전체 화면의 다국어화는 후속 작업으로 관리한다.

## 데이터·시연 고지 정책

- [관광 데이터](../../data/places.json)와 `public/places/` 사진은 검토 전(`DRAFT`) 자료다.
- 운영 승인·영업시간·요금·예약·최적 동선을 보장하지 않으며 여행 패스는 결제·혜택 이용권이 아니다.
- 목록·상세에 검토 전 상태, 원문 확인일(`checkedOn`, 현재 운영 확인일 아님), 공식 출처, 사진 저작자·라이선스·크롭 안내를 표시한다.

## 세션·개인정보·사용 제한

브라우저별 무작위 32바이트 `tourpass-session` 쿠키(`HttpOnly`, `SameSite=Lax`, `Path=/`, 30일)의 SHA-256 해시로 소유권을 구분한다. 익명 사용자는 쿠키 삭제·만료 후 기존 여행에 재접근할 수 없다.

네이버 로그인을 선택하면 현재 익명 여행·기록·사진을 계정에 연결하고 같은 네이버 계정으로 다른 브라우저에서도 조회한다. 로그인 시 세션을 교체하고 이전 세션을 폐기한다. 이미 로그인한 계정에서 다른 계정으로 전환할 때는 여행을 옮기지 않는다. 로그아웃은 현재 세션을 폐기하고 빈 익명 보관함으로 전환하며 계정 여행은 유지한다. 네이버 동일인 식별자의 해시만 저장하고 이름·이메일·프로필 사진·접근/갱신 토큰은 저장하지 않는다. 로그인 키 미설정 시 안내와 비활성 버튼을 제공하고 익명 기능은 유지한다. OAuth state는 브라우저 세션과 연결해 10분 이내 한 번만 사용한다.

| 외부 전송 | 허용 데이터 |

| CLOVA 안내·편집 | 질문·편집 요청과 최근 대화 최대 6개를 전송한다. |

## 핵심 기능 요구사항

### 경기도 지역 선택 지도

- 관광지 탐색 화면에 경기도 외곽 형태와 시·군별 경계를 표시한다. [경기도 행정구역 현황](https://www.gg.go.kr/contents/contents.do?ciIdx=468&menuId=1831)의 2026-07-01 기준 28개 시·3개 군을 기준으로 하며, 군 지역도 같은 방식으로 선택한다. 일반구는 소속 시 단위로 묶고 서울·인천은 선택 대상에서 제외한다.
- 장소 찾기 기본 화면의 상단을 지도와 선택 도시 관광지 목록으로 구성한다. 데스크톱에서는 지도가 왼쪽 약 2/3, 목록이 오른쪽 약 1/3을 차지한다. 관광지 수·`경기 둘러보기` 소개, 작업 선택과 배너·카탈로그는 이 영역 아래에 배치한다. 관광지 수는 실제 등록 수로 표시한다. 모바일에서는 지도 다음에 도시 관광지 목록을 세로로 배치한다.
- 실제 경계 자료를 가공한 SVG로 표시하고 지도 아래에 자료 출처·경계 기준일·가공 여부를 안내한다. 경계와 좌표계·이용 조건은 [기술 구조](../03-tech/01-architecture.md#경기도-지역-선택-지도)에 따라 확인한다.
- 지도 오른쪽 상단에 [지도 현재 날씨](#지도-현재-날씨)의 아이콘과 그 아래 기온을 표시한다. 북쪽 화살표(`N`)는 지도 하단에 유지한다.
- 처음에는 특정 시·군을 선택하지 않는다. 영역을 클릭·터치하거나 키보드로 선택하면 해당 지역의 이름과 선택 상태를 표시한다. 마우스 올림·키보드 초점과 확정 선택은 구분한다.
- 한 번에 한 지역을 선택하며 다른 지역을 선택하면 이전 선택을 교체한다. `경기도 전체 보기`로 선택을 해제한다. 지역 선택만으로 담은 여행과 저장된 기록을 변경하지 않는다.
- 지도와 같은 선택 상태를 공유하는 지역 목록을 함께 제공한다. 작은 영역도 목록으로 선택할 수 있고, 키보드와 모바일에서 지역 이름·초점·선택 상태를 확인할 수 있어야 한다.
- 시·군을 선택하면 오른쪽에 해당 시·군 식별자와 일치하는 등록 관광지만 표시한다. 시흥은 기존 20곳의 상세 보기와 여행 담기를 제공하고, 자료가 없는 지역은 `관광 정보 준비 중`으로 안내한다. 시흥 자료를 다른 시·군의 자료처럼 표시하지 않는다.
- 시·군 선택과 기존 시흥 권역 필터는 별도로 관리한다. 오른쪽 관광지 목록과 지도 현재 날씨는 시·군 식별자로 연결하며, 기존 권역 필터를 도시 이름으로 덮어쓰지 않는다.

### 지도 현재 날씨

- 경기도 31개 시·군에서 선택한 지역의 현재 날씨를 표시한다. 도시 미선택·선택 해제 시에는 수원시 대표 지점을 사용하고 항상 지역명과 `기준`을 표시한다. 하나의 지점 값을 경기도 전체 날씨로 안내하지 않는다.
- 대표 위경도는 검토한 행정구역 경계 안의 대표 지점을 사용한다. Open-Meteo 기상 모델 기반의 현재 기온·날씨 상태를 조회하고 자료 기준 시각을 표시한다. 지도 날씨 카드에서는 공급자 링크·모델 설명과 `시·군 대표 지점` 문구를 생략하고 출처·대표 좌표는 API 응답과 기술 문서에 보존한다. 시·군 전체의 균일한 기상이나 현장 관측값으로 보장하지 않는다.
- 기존 공용 아이콘을 재사용하고 아이콘 아래에 섭씨 기온을 표시한다. 음수·0°C를 지원하고 로딩·실패 시 미확인 값(`--°C`)과 상태를 안내한다. 조회 실패 시 재시도를 제공하며 고정 10°C나 다른 도시의 이전 값을 표시하지 않는다.
- 지역별 10분 캐시와 동시 요청 병합을 적용한다. 도시 전환·탭 이동 시 종료된 화면의 응답을 무시하고 다른 지역의 결과가 현재 화면을 덮어쓰지 않게 한다. 현재 화면은 캐시 만료 시 갱신한다.
- 명시적인 시연 모드에서는 `예시 날씨`를 표시한다. 실제 API 실패를 예시 데이터로 자동 대체하지 않는다. 기존 시흥권 날씨 API·예보·추천 동작은 유지한다.

### 시·군별 관광 데이터 확장

- 한국관광공사 TourAPI의 국문 관광지·문화시설 정보를 수집해 경기도 31개 시·군 지도에 연결한다. 시흥의 기존 20곳과 장소 ID는 유지하며, 다른 시·군은 유효한 자료를 최대 20곳씩 먼저 제공한다. 제공 자료가 적으면 실제 확보한 수만 표시한다.
- 법정동 시도 코드·시군구 코드와 주소를 확인해 기존 지도 식별자로 연결한다. 일반구는 소속 시로 합치고, 다른 시도·좌표 누락·중복 자료는 포함하지 않는다. 자료 확인일과 공급자 콘텐츠 ID·갱신 시점을 보존한다.
- 목록·상세·여행 담기·저장·번역·음성은 기존 관광지와 같은 방식으로 제공한다. 신규 좌표를 시흥의 기본 위치로 대체하지 않으며, 다른 시·군이 포함된 코스는 경기도 경계와 실제 좌표를 기준으로 표시한다.
- 사진은 출처와 공공누리 제1유형을 확인한 자료만 사용한다. 확인할 수 없는 사진은 생략하고 관광지 정보는 제공한다. 전체 자료는 기존 검토 전 정책을 적용하며 현재 운영·요금·예약을 확인한 것으로 표시하지 않는다.
- 수집은 개발용 명령으로 실행하고 결과를 정적 카탈로그로 저장한다. 인증키는 로컬 환경 변수로만 읽고 브라우저·생성 데이터·로그·Git에 포함하지 않는다. 기존 시흥권 날씨 추천은 해당 권역의 관광지만 사용한다.

### 탐색·추천·날씨

- 이름·지역·설명·태그 검색과 지역 필터를 제공한다. 지역 필터는 AI 추천 후보에도 적용한다.
- 카드와 지도를 전환한다. 네이버 지도(Web Dynamic Map) Client ID가 설정되면 실제 네이버 지도에 마커·요약·상세·여행 담기와 패스 순서·동선, 네이버 지도 외부 보기를 제공한다. 키가 없거나 지도 로드·인증에 실패하면 안내 문구와 함께 내장 SVG 개략 지도로 자동 전환한다.
- CLOVA 키가 있으면 1~5곳을 추천하고 서버가 ID·중복·개수·지역을 검증한다. 키가 없을 때만 키워드·만족도 기반 결정론적 데모를 표시하며, 키 설정 후 실패·시간 초과는 오류로 알린다.
- 경기(시흥권) 전체·10개 권역의 현재 기온·체감온도·습도·풍속·강수량, 5일 예보와 야외·실내 활동 가이드를 제공한다. Open-Meteo `live` 조회 실패 시 결정론적 `demo`로 전환하고 출처 모드를 표시한다. 추천 장소는 상세·여행 담기로 연결한다.

### 여행 패스·방문 기록

- 중복 없는 1~8곳을 담아 위로 이동·제외하고 이름(1~60자)·날짜(`YYYY-MM-DD`)와 저장한다. `이 제안으로 구성하기`는 담은 목록을 교체한다.
- 같은 브라우저에서 새로고침·서버 재시작 후에도 여행을 유지한다. 장소별 만족도(1~5점)·메모(최대 500자)를 수정하고 코스 지도에서 순서·기록 상태를 확인한다.

### 마이

- 다섯 번째 하단 메뉴에서 저장한 여행 수와 방문 기록을 남긴 고유 장소 수를 확인하고 내 여행으로 이동한다. 보관함 연결 전에는 집계를 표시하지 않는다.
- 선호 지역과 활동 취향(최대 500자)을 현재 브라우저에 저장하고, 새로고침 후 추천 입력의 기본값으로 불러온다. 추천 화면에서는 이번 여행에 맞게 변경할 수 있으며 마이에서 저장할 때만 기본값을 갱신한다.
- 취향은 브라우저 저장소에 보관하며 추천을 요청할 때 기존 추천 정책에 따라 전송한다. 익명 여행의 쿠키 만료·삭제와 취향의 브라우저 데이터 삭제에 따른 보관 제한을 안내한다. 네이버 로그인 상태·로그인·로그아웃을 제공하며 여행 취향은 로그인 후에도 브라우저에만 저장한다.

### 도우미 확장

| 기능 | 요구사항 | 키 미설정 시 |
| --- | --- | --- |
| 관광 안내 | 관련 장소 최대 3곳을 근거로 전달하고 `sourceIds`를 검증한다. 예약·요금·가격·운영·휴무·주차·휠체어·입장 질문은 AI 없이 확인 불가·공식 출처를 안내한다. | AI 답변과 구분한 자료 검색 결과를 표시한다. |
| 여행 수정 | `propose_itinerary` 제안과 `revision`을 미리 본 뒤 사용자가 적용한다. 소유권·리비전을 재검사하고 충돌은 `409`로 알린다. 기록·사진 보유 장소 삭제와 포스터 행사 날짜 변경을 차단한다. | N번째 제외·순서 반전·정확한 장소명 추가 규칙 데모를 제공한다. |
| 음성·번역 | 장소 상세 음성과 장소·여행 번역을 제공한다. | 설정 안내와 비활성 버튼을 표시하며 호출은 `503`을 반환한다. |
| 사진·일기 | 2MB 이하 단일 페이지 JPEG·PNG·WebP를 디코딩·회전·1600×1600 이내 축소·JPEG 재인코딩해 메타데이터를 제거한다. 같은 여행·장소 사진은 교체하며 일기 초안은 사용자가 메모에 반영·저장해야 확정한다. | 사진 저장은 가능하고 일기 생성은 `503`을 반환한다. |
| 포스터 | OCR·Studio로 행사명·날짜·장소 초안을 만든다. 연도·단일 날짜가 모호하면 날짜를 비운다. 사용자가 원본과 비교하고 카탈로그 장소를 직접 골라 `event.origin = 'poster'` 여행으로 저장한다. | 직접 입력·저장은 가능하고 인식은 `503`을 반환한다. |
