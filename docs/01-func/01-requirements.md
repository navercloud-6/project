# 요구사항 — 경기 하루이음

[문서 안내](../../README.md#문서-분류-기준)

## 범위

- **현재 구현**: 경기도 31개 시·군의 관광지 탐색, CLOVA 사전 라벨링·Reranker 기반 AI 여행 검색·추천, 패스 구성, 방문 기록, 관광 안내·여행 편집, 번역·음성·포스터 인식, 경기도 31개 시·군 날씨를 제공하는 Next.js 풀스택 MVP다.
- **제외 범위**: 결제·할인·제휴·상점 인증, 관리자·가맹점 기능, Object Storage, 대규모 벡터 DB·임베딩은 제외한다.
- **확장 목표**: 대상 지역은 경기도로 한정하며, 해외 관광객용 영어 지원(후속 일본어·중국어)과 시·군 단위 AI·추천 연계는 후속 작업으로 관리한다.

## 데이터·시연 고지 정책

- [관광 데이터](../../data/places.json)와 `public/places/` 사진은 검토 전(`DRAFT`) 자료이며, 운영·영업시간·요금·예약·최적 동선과 결제·혜택을 보장하지 않는다.
- 목록·상세에 검토 전 상태, 원문 확인일(`checkedOn`, 현재 운영 확인일 아님), 공식 출처, 사진 저작자·라이선스·크롭 안내를 표시한다.

## 세션·개인정보·사용 제한

브라우저별 32바이트 무작위 `tourpass-session` 쿠키(`HttpOnly`, `SameSite=Lax`, `Path=/`, 30일)의 SHA-256 해시로 소유권을 구분한다. 익명 여행은 쿠키 삭제·만료 후 재접근할 수 없다.

네이버 로그인 시 익명 여행·기록·사진을 계정에 연결하고 세션을 교체하며 이전 세션을 폐기한다(다른 계정 전환 시 여행은 이전하지 않는다). 로그아웃은 현재 세션을 폐기하고 빈 익명 보관함으로 전환하며 계정 여행은 유지한다. 동일인 식별자의 해시만 저장하고 프로필·토큰은 저장하지 않는다. 로그인 키 미설정 시 안내와 비활성 버튼을 제공하며 OAuth `state`는 세션과 연결해 10분 이내 1회만 사용한다.

| 외부 전송 | 허용 데이터 |
| --- | --- |
| CLOVA 추천 | 취향과 최근 10개 여행의 장소별 만족도(1~5점)만 전송하며 방문 메모는 제외한다. |
| CLOVA 안내·편집 | 질문·편집 요청과 최근 대화 최대 6개를 전송한다. |
| Papago 번역 | 장소 설명 또는 여행 이름·날짜·장소 설명을 전송하며 방문 메모는 제외한다. |
| CLOVA Vision | 소유자 전용 비공개 사진 중 사용자가 일기 초안을 요청할 때만 전송한다. |
| CLOVA OCR·Studio | 포스터에서 텍스트·일정 초안을 추출하며 원본 이미지는 저장하지 않는다. |

## 핵심 기능 요구사항

### 경기도 지역 선택 지도

- 2026-07-01 기준 경기도 28개 시·3개 군의 경계를 SVG로 표시한다(일반구는 소속 시로 병합, 서울·인천 제외). 지도 아래에 출처·기준일·가공 여부를 안내한다.
- 경기 둘러보기 상단에 제목과 작업 전환(`장소 찾기`·`담은 여행`)을 두고, `장소 찾기` 최상단에 AI 통합 여행 검색·추천 바를 배치한다. 그 아래 왼쪽 경기도 지도(약 2/3)와 오른쪽 선택 도시 관광지 목록(약 1/3, 모바일은 세로)을 두고, 하단에 검색 결과 카탈로그를 배치한다.
- 지도 우측 상단에는 선택한 시·군(미선택 시 수원)의 현재 날씨를 아이콘 위·기온 아래로 표시하고 지역·상태·기준 시각을 안내한다. 6종 아이콘, 로딩·오류·재시도와 명시적 시연 모드를 지원하며 조회 실패를 예시 기온으로 대체하지 않는다. 북쪽 화살표(`N`)는 하단에 둔다.
- 초기에는 미선택 상태이며 클릭·터치·키보드로 단일 시·군을 선택하고 `경기도 전체 보기`로 해제한다. 마우스 올림·초점과 확정 선택을 구분하며 같은 상태를 공유하는 지역 목록을 함께 제공한다.
- 선택 시 `cityId`가 일치하는 관광지만 오른쪽에 표시하고 자료가 없으면 `관광 정보 준비 중`을 안내한다. 지역 선택만으로 담은 여행·기록·시흥 권역 필터를 변경하지 않는다.

### 시·군별 관광 데이터 확장

- 한국관광공사 TourAPI 국문 관광지·문화시설을 개발용 명령으로 수집해 정적 카탈로그로 저장한다. 기존 시흥 20곳과 ID를 유지하고 나머지 시·군은 유효 자료를 최대 20곳씩 추가한다.
- 법정동 시도·시군구 코드와 주소로 지도 식별자를 대조하며 일반구 병합, 타 시도·좌표 누락·중복 제거, 확인일·콘텐츠 ID·갱신일 보존을 적용한다.
- 사진은 공공누리 제1유형 확인 자료만 사용하고 미확인 사진은 생략한다. 인증키는 로컬 환경 변수로만 읽고 저장소·브라우저·로그에 남기지 않는다.

### 탐색·추천·날씨

- 609곳 관광지 카탈로그는 CLOVA Studio 배치 스크립트(초기 규칙 기반 부트스트랩 포함)로 실내·야외, 테마(호수·바다·산/계곡·박물관/전시 등), 동행, 여행 방식, 핵심 검색어 라벨을 사전 생성해 저장한다.
- 최상단 AI 통합 검색창은 입력 즉시 라벨·이름·지역·설명·태그로 카탈로그를 필터링하고, 지역 필터와 카드·지도 전환을 제공한다. 네이버 지도 Client ID가 있으면 네이버 지도를 표시하고 미설정·실패 시 내장 경기도 SVG 지도로 폴백한다.
- AI 검색·추천 실행 시 라벨·키워드·동의어·과거 만족도로 1차 후보(최대 20곳)를 추출한 뒤, CLOVA 키가 있으면 CLOVA Studio Reranker로 질문 의도에 맞는 연관 관광지를 선별하고 CLOVA Studio가 1~5곳 맞춤 코스를 추천한다(서버가 ID·중복·개수·지역을 검증). Reranker 실패 시 1차 라벨 후보로 폴백하며, 키가 없을 때만 결정론적 라벨 데모 추천과 연관 관광지를 표시한다. 키 설정 후 추천 오류·시간 초과는 실패로 알린다.
- 경기도 전체(경기도청·수원 기준)와 31개 시·군의 현재 기상, 5일 예보, 활동 가이드와 해당 지역 추천 장소를 제공한다. Open-Meteo 실패 시 데모로 폴백하고 모드를 표시한다.
- 지도와 날씨 탭은 선택한 시·군을 공유하고 같은 시·군의 기상 좌표를 사용한다. 도시 전환 중에는 이전 도시의 날씨·추천을 숨기며 탭 복귀 후에도 선택을 유지한다. 지도 현재 날씨는 성공 응답을 10분간 캐시하고 같은 도시의 동시 요청을 합친다.

### 여행 패스·방문 기록·프로필

- 중복 없는 1~8곳을 담아 순서 변경·제외 후 이름(1~60자)·날짜(`YYYY-MM-DD`)와 저장한다. 추천 적용 시 담은 목록을 교체한다.
- 새로고침·재시작 후에도 여행을 유지하고 장소별 만족도(1~5점)·메모(최대 500자)와 코스 지도를 제공한다.
- 프로필 탭에서 연결 완료 후 저장 여행 수·기록 고유 장소 수를 표시하고, 선호 지역·취향(최대 500자)을 브라우저에 저장해 추천 기본값으로 사용한다. 네이버 로그인·로그아웃과 보관 정책을 안내한다.

### 도우미 확장

| 기능 | 요구사항 | 키 미설정 시 |
| --- | --- | --- |
| 관광 안내 | 관련 장소 최대 3곳을 근거로 전달하고 `sourceIds`를 검증한다. 운영·요금·예약·주차·휠체어 질문은 AI 없이 확인 불가와 공식 출처를 안내한다. | 자료 검색 결과를 표시한다. |
| 여행 수정 | `propose_itinerary` 제안과 `revision`을 미리 본 뒤 적용한다. 소유권·리비전 충돌은 `409`로 알리고, 기록·사진 보유 장소 삭제와 포스터 행사 날짜 변경을 차단한다. | N번째 제외·순서 반전·정확한 장소명 추가 데모를 제공한다. |
| 음성·번역 | 장소 음성과 장소·여행 번역을 제공한다. | 비활성 버튼·안내를 표시하고 호출은 `503`을 반환한다. |
| 사진·일기 | 2MB 이하 단일 페이지 JPEG·PNG·WebP를 검증·회전·1600px 축소·JPEG 재인코딩한다. 일기 초안은 메모 반영·저장 시 확정한다. | 사진 저장만 가능하고 일기는 `503`을 반환한다. |
| 포스터 | OCR·Studio로 행사명·날짜·장소 초안을 만든다(모호한 날짜는 공란). 사용자가 확인 후 카탈로그 장소를 골라 `event.origin='poster'`로 저장한다. | 직접 입력·저장만 가능하고 인식은 `503`을 반환한다. |
