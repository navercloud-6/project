# 요구사항 — 경기 하루이음

[문서 안내](../../README.md#문서-분류-기준)

## 범위

- **현재 구현**: 경기도 31개 시·군의 관광지 탐색, CLOVA 사전 라벨링·Reranker 기반 AI 여행 검색·추천, 패스 구성, 방문 기록, 관광 안내·여행 편집, 번역·음성·포스터 인식, 경기도 31개 시·군 날씨를 제공하는 Next.js 풀스택 MVP다.
- **제외 범위**: 결제·할인·제휴·상점 인증, 관리자·가맹점 기능, Object Storage, 대규모 벡터 DB·임베딩은 제외한다.
- **확장 목표**: 대상 지역은 경기도로 한정하며, 해외 관광객용 영어 지원(후속 일본어·중국어)과 시·군 단위 AI·추천 연계는 후속 작업으로 관리한다.

## 데이터·시연 고지 정책

- [관광 데이터](../../data/places.json)와 `public/places/` 사진은 검토 전(`DRAFT`) 자료이며, 운영·영업시간·요금·예약·최적 동선과 결제·혜택을 보장하지 않는다.
- 목록·상세에 검토 전 상태, 원문 확인일(`checkedOn`, 현재 운영 확인일 아님), 공식 출처, 사진 저작자·라이선스·크롭 안내를 표시한다.

## 세션·개인정보·사용 제한

브라우저별 32바이트 무작위 `tourpass-session` 쿠키(`HttpOnly`, `SameSite=Lax`, `Path=/`, 30일)의 SHA-256 해시로 소유권을 구분한다. 익명 여행은 쿠키 삭제·만료 후 재접근할 수 없다.

네이버 로그인 시 익명 여행·기록·사진을 계정에 연결하고 세션을 교체하며 이전 세션을 폐기한다(다른 계정 전환 시 여행은 이전하지 않는다). 로그아웃은 현재 세션을 폐기하고 빈 익명 보관함으로 전환하며 계정 여행은 유지한다. 동일인 식별자의 해시만 저장하고 프로필·토큰은 저장하지 않는다. 로그인 키 미설정 시 안내와 비활성 버튼을 제공하며 OAuth `state`는 세션과 연결해 10분 이내 1회만 사용한다.

## 핵심 기능 요구사항

### 경기도 지역 선택 지도

- 2026-07-01 기준 경기도 28개 시·3개 군의 경계를 SVG로 표시한다(일반구는 소속 시로 병합, 서울·인천 제외). 지도 아래에 출처·기준일·가공 여부를 안내한다.
- 경기 둘러보기는 제목 → AI 통합 여행 검색·추천 바 → 경기도 지도·선택 도시 관광지 목록 → 작업 전환(`장소 찾기`·`담은 여행`) → 검색 결과 카탈로그 순서로 배치한다. 지도와 도시 목록은 약 2:1로 나누고 모바일에서는 세로로 배치한다. `담은 여행`에서는 검색·지도를 접고 작업 전환 아래에 여행 편집을 표시한다.
- 지도 우측 상단에는 선택한 시·군(미선택 시 수원)의 현재 날씨를 아이콘 위·기온 아래로 표시하고 지역·상태·기준 시각을 안내한다. 6종 아이콘, 로딩·오류·재시도와 명시적 시연 모드를 지원하며 조회 실패를 예시 기온으로 대체하지 않는다. 북쪽 화살표(`N`)는 하단에 둔다.
- 초기에는 미선택 상태이며 클릭·터치·키보드로 단일 시·군을 선택하고 `경기도 전체 보기`로 해제한다. 마우스 올림·초점과 확정 선택을 구분하며 같은 상태를 공유하는 지역 목록을 함께 제공한다.
- 선택 시 `cityId`가 일치하는 관광지만 오른쪽에 표시하고 자료가 없으면 `관광 정보 준비 중`을 안내한다. 지역 선택만으로 담은 여행·기록·시흥 권역 필터를 변경하지 않는다.

### 시·군별 관광 데이터 확장

- 한국관광공사 TourAPI 국문 관광지·문화시설을 개발용 명령으로 수집해 정적 카탈로그로 저장한다. 기존 시흥 20곳과 ID를 유지하고 나머지 시·군은 유효 자료를 최대 20곳씩 추가한다.
- 법정동 시도·시군구 코드와 주소로 지도 식별자를 대조하며 일반구 병합, 타 시도·좌표 누락·중복 제거, 확인일·콘텐츠 ID·갱신일 보존을 적용한다.
- 사진은 공공누리 제1유형 확인 자료만 사용하고 미확인 사진은 생략한다. 인증키는 로컬 환경 변수로만 읽고 저장소·브라우저·로그에 남기지 않는다.

### 탐색·추천·날씨

- 609곳 관광지 카탈로그는 CLOVA Studio 배치 스크립트(초기 규칙 기반 부트스트랩 포함)로 실내·야외, 테마(호수·바다·산/계곡·박물관/전시 등), 동행, 여행 방식, 핵심 검색어 라벨을 사전 생성해 저장한다.
- 최상단 AI 통합 검색창은 입력 즉시 라벨·이름·지역·설명·태그로 카탈로그를 필터링한다. 검색 패널에는 간결한 제목·결과 수, 입력·지역 선택·실행 버튼, 빠른 테마만 두고 기술 설명과 반복 안내는 생략한다. 검색 결과 카탈로그에서 카드·지도를 전환하며, 네이버 지도 Client ID가 있으면 네이버 지도를 표시하고 미설정·실패 시 내장 경기도 SVG 지도로 폴백한다.
- 자연어의 시·군명은 지역 제약으로 적용하고, 동행·장소 구분·테마·활동 조건은 모두 충족해야 한다. 같은 조건의 동의어는 함께 처리하며 `산책`을 `산`으로 확장하지 않는다. 검색 미리보기와 AI 후보는 같은 필터를 사용하고, 일치하는 장소가 없으면 다른 지역·조건을 안내하며 범위를 임의로 넓히지 않는다.
- AI 검색·추천 실행 시 라벨·키워드·동의어·과거 만족도로 1차 후보(최대 20곳)를 추출한 뒤, CLOVA 키가 있으면 CLOVA Studio Reranker로 질문 의도에 맞는 연관 관광지를 선별하고 CLOVA Studio가 최대 3곳 맞춤 코스를 추천한다(서버가 ID·중복·개수·지역을 검증). 후보가 충분하면 3곳을 추천한다. Reranker 실패 시 1차 라벨 후보로 폴백하며, 키가 없을 때만 결정론적 라벨 데모 추천과 연관 관광지를 표시한다. 키 설정 후 추천 오류·시간 초과는 실패로 알린다.
- 검색 미리보기와 최종 추천은 각각 최대 3곳을 간결한 목록으로 표시하고, 나머지 조건 일치 장소는 전체 검색 결과에서 확인한다. 미리보기의 조건 일치 수와 완료된 추천 수를 구분하고, 검색어·지역을 바꾸면 이전 추천을 지우며 진행 중이던 이전 응답은 표시하지 않는다. 장소 항목을 누르면 기존 관광지 카드와 같은 상세창을 열고 여행 담기는 별도 버튼으로 제공한다.
- 경기도 전체(경기도청·수원 기준)와 31개 시·군의 현재 기상, 5일 예보, 활동 가이드와 해당 지역 추천 장소를 제공한다. Open-Meteo 실패 시 데모로 폴백하고 모드를 표시한다.
- 지도와 날씨 탭은 선택한 시·군을 공유하고 같은 시·군의 기상 좌표를 사용한다. 도시 전환 중에는 이전 도시의 날씨·추천을 숨기며 탭 복귀 후에도 선택을 유지한다. 지도 현재 날씨는 성공 응답을 10분간 캐시하고 같은 도시의 동시 요청을 합친다.
- 같은 날씨 응답으로 오늘의 옷차림을 제공한다. 오늘 최고기온의 8개 구간(4°C 이하~28°C 이상, '이하' 경계)으로 겉옷·상의·하의·소품을 정하고, 최저·최고기온을 넣은 이유 문장을 표시한다. AI를 호출하지 않는 규칙 기반이며 같은 입력에는 같은 결과를 준다.
- 강수확률 60% 이상·비(우산·방수 신발), 비와 풍속 8m/s 이상(우비), 강한 비(우비·여벌 양말), 눈(미끄럼 방지 신발), 최고 4°C 이하 또는 체감 0°C 이하(목도리·장갑·귀마개), 최저 -5°C 이하(핫팩), 풍속 8m/s 이상(바람막이·끈 있는 모자), 해안 시·군의 최고 22°C 이하(해풍 바람막이), 최고 12°C 이상에서 일교차 8°C 이상(얇은 겉옷), 최고 28°C 이상의 맑은 날(선글라스·선크림·물)에 추가 준비물과 근거 문장을 안내한다. 두꺼운 겉옷 구간(최고 8°C 이하)에서는 바람막이 대신 방풍 겉옷과 해풍 체감 문장을 안내한다. 데모 모드에서는 데모 기상 기준임을 표시한다.
- 날씨 탭에서 선택 시·군의 맛집 최대 5곳을 NAVER 지역 검색(리뷰 많은 순)으로 보여 준다. 분류에 술집이 있거나 주소가 경기도·선택 시·군이 아니면 제외한다(예: `광주시` 검색의 광주광역시). 인기 메뉴는 블로그 후기 한 건에 실제로 적힌 이름만 최대 3개 표시하며 맛 평가·가격·영업 여부는 보장하지 않는다. 지역별 결과를 10분간 공유하고 검색 키 미설정 시 설정 안내만 표시한다. 통합 안내 원고는 명소 다음에 맛집 최대 3곳을 명소 추천 이유와 같은 AI 요청에서 블로그 후기 표현·음식 종류·검증된 메뉴를 근거로 한 문장씩 말하고(같은 길이·숫자·계절·이름 검사, 확인된 메뉴가 있는 맛집은 메뉴를 하나 이상 꼭 포함), 검사 실패 시 "○○는 일식당인데 ○○이 유명해요"처럼 음식 종류·메뉴 규칙 문장으로 말하며 맛집 조회 실패 시 맛집 없이 안내한다.
- 여행 도우미는 경기도 지도로 시·군을 고르면 안전 안내 → 통합 안내 원고·음성 → 오늘 날씨·옷차림 → 추천 명소(원고와 같은 순서·추천 이유) → 맛집 순서로 보여 준다. 원고는 자동으로 만들고 음성도 미리 만들어 듣기 버튼으로 바로 재생한다. 기존 관광 안내·행사 등록 화면은 이 탭에서 제외했다(API·컴포넌트는 유지).
- 안전 안내: 기상청 특보 발효 현황에서 선택 시·군(기상청 구역명)에 걸린 주의보·경보·예비특보와 최근 24시간 국내 지진(경기도 발생 또는 규모 3.0 이상)·경기도에서 느낀 해외 지진을 알림 상자로 보여 주고, 통합 안내 원고 첫 인사 뒤에 AI 없이 자료 그대로 먼저 말한다. 특보 종류별로 정해진 주의 한마디(건조: 화재·산불, 폭염: 야외 활동 자제, 한파: 동상·빙판길 등)를 덧붙인다. 조회 실패 시 안내 없이 계속한다.

### 여행 패스·방문 기록·프로필

- 중복 없는 1~8곳을 담아 순서 변경·제외 후 이름(1~60자)·날짜(`YYYY-MM-DD`)와 저장한다. 추천 적용 시 담은 목록을 교체한다.
- 새로고침·재시작 후에도 여행을 유지하고 장소별 만족도(1~5점)·메모(최대 500자)와 코스 지도를 제공한다.
- 프로필 탭에서 연결 완료 후 저장 여행 수·기록 고유 장소 수를 표시하고, 선호 지역·취향(최대 500자)을 브라우저에 저장해 추천 기본값으로 사용한다. 네이버 로그인·로그아웃과 보관 정책을 안내한다.

| 관광 안내 | 관련 장소 최대 3곳을 근거로 전달하고 `sourceIds`를 검증한다. 운영·요금·예약·주차·휠체어 질문은 AI 없이 확인 불가와 공식 출처를 안내한다. | 자료 검색 결과를 표시한다. |
| 여행 수정 | `propose_itinerary` 제안과 `revision`을 미리 본 뒤 적용한다. 소유권·리비전 충돌은 `409`로 알리고, 기록·사진 보유 장소 삭제와 포스터 행사 날짜 변경을 차단한다. | N번째 제외·순서 반전·정확한 장소명 추가 데모를 제공한다. |
| 음성·번역 | 장소 음성과 장소·여행 번역을 제공한다. | 비활성 버튼·안내를 표시하고 호출은 `503`을 반환한다. |
| 통합 안내 | 날씨 탭에서 선택 시·군의 날씨→옷차림·준비물→추천 명소 3곳을 1분 원고로 만들고 `nara`(한국어)·`clara`(영어, Papago 번역) 음성으로 제공한다. 원고는 옷·준비물 이름을 바꾸지 않고 `즐거운 여행 되세요!`로 끝나며 도우미 한도를 공유한다. 키 설정 후 AI 오류는 실패로 알린다. AI는 인사·날씨·옷차림·준비물 부분과 명소별 추천 이유 한 문장(관광 소개·태그와 NAVER 블로그 후기 최대 3건을 근거로 볼거리·할 거리를 담은 친근한 해요체 70자 이내, 숫자·다른 장소 이름·특정 시기 행사 금지, 오늘 계절(달 기준, 최고 5°C 이하는 겨울·최저 20°C 이상은 여름)과 맞지 않는 꽃·단풍·물놀이·피크닉 등 표현 금지, 위반 시 태그 기반 규칙 문장)만 작성하고 명소·맛집 이름·메뉴와 끝인사는 서버가 자료 그대로 붙인다. AI 부분에 자료에 없는 숫자(영하 여부 포함)나 오늘 옷차림에 없는 옷·준비물 이름이 있으면 1회 재요청하고, 그래도 다르면 규칙 원고로 안내한다. | CLOVA Studio 미설정 시 규칙 원고, Voice 미설정 시 원고만 표시, Papago 미설정 시 영어는 비활성·`503`이다. |
| 사진·일기 | 2MB 이하 단일 페이지 JPEG·PNG·WebP를 검증·회전·1600px 축소·JPEG 재인코딩한다. 일기 초안은 메모 반영·저장 시 확정한다. | 사진 저장만 가능하고 일기는 `503`을 반환한다. |
| 포스터 | OCR·Studio로 행사명·날짜·장소 초안을 만든다(모호한 날짜는 공란). 사용자가 확인 후 카탈로그 장소를 골라 `event.origin='poster'`로 저장한다. | 직접 입력·저장만 가능하고 인식은 `503`을 반환한다. |
