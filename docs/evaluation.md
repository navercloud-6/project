## 평가 영역과 근거 문서

총 100점(4개 영역) 기준으로 각 세부 항목의 근거 문서를 연결한다.

| 영역 (배점) | 세부 항목 | 관련 문서 및 현황 |
| --- | --- | --- |
| 1. 기획·주제 적합성 (20) | 주제·문제 정의, 서비스 목적·방향성, 조원 역할 | [요구사항 범위](01-func/01-requirements.md#범위), [핵심 기능](01-func/01-requirements.md#핵심-기능-요구사항), [디자인 기준](02-uxui/01-design.md)에 정리했다. 조원별 역할 표는 미확정이다. |
| 2. 핵심 기능·기술 구현도 (35) | 실제 동작, 기술 스펙·아키텍처, API·DB·서버 안정성 | [사용 방법](../README.md#사용-방법), [최신 판정](04-test/01-verification.md#최신-판정), [기술 구조](03-tech/01-architecture.md), [배포 가이드](05-ops/01-deploy.md)에서 관리한다. |
| 3. 데이터·AI 활용도 (25) | 외부 데이터·OCR·RAG·LLM 활용, 시행착오·개선 이력 | [관광 데이터](../data/places.json), Open-Meteo, [도우미 확장](01-func/01-requirements.md#도우미-확장)을 구현했고 이력은 Git 커밋·[최신 판정](04-test/01-verification.md#최신-판정)·[남은 작업과 리스크](03-tech/01-architecture.md#남은-작업과-리스크)에 둔다. |
| 4. 발표 준비도 (20) | PPT 구성, 시연 동영상, 10분 발표·질의응답 | 5개 탭 핵심 시나리오, 아키텍처·AI 활용·개선 이력 중심으로 별도 제작한다. |

## 미확정 및 발표 준비 항목

| 항목 | 대기 이유 | 재개 조건·작업 |
| --- | --- | --- |
| 조원별 역할 기재 | 조원 명단과 담당 영역을 확정하지 않았다. | 역할 확정 후 본 문서에 분담표를 추가한다. |
| 발표 PPT·시연 동영상 | 발표 일정과 제출 양식에 맞춰 제작해야 한다. | 시연 시나리오와 NAVER 실키 범위를 확정한 뒤 촬영·제작한다. |
