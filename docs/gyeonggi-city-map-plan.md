# 경기도 시·군 선택 지도 작업 계획

[문서 안내](../README.md#관련-문서) · [요구사항](01-func/01-requirements.md#경기도-지역-선택-지도) · [기술 구조](03-tech/01-architecture.md#경기도-지역-선택-지도)

## 현재 상태와 후속 목표

- **현재 구현**: 31개 시·군 SVG 지도·도시 목록, 시흥 20곳과 TourAPI 자료 연동, 31개 시·군 날씨 조회를 완료했다.
- **후속 목표**: AI 추천의 시·군 계약 연계와 영어 UI는 별도 과제로 진행한다([검증 현황](04-test/01-verification.md#최신-판정)).

## 대기 항목과 재개 조건

| 항목 | 대기 이유 | 재개 조건 |
| --- | --- | --- |
| 관광 자료 운영 검토 | 운영·요금·예약이 미확인이다. | 공식 안내·라이선스 검토 후 필요 시 `npm run data:tourapi`로 갱신한다. |
| 시·군 단위 서버 연계 | `region` 계약이 시흥 권역 기준이다. | 시·군 계약 확정 후 API·OpenAPI를 함께 변경한다. |
| 실브라우저 회귀 검증 | 로컬 자동 브라우저 시간 초과로 미완료했다. | 로컬·배포 서버에서 390px·1365px 핵심 흐름을 실확인한다. |
