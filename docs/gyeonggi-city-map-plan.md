# 경기도 시·군 선택 지도 작업 계획

[문서 안내](../README.md#관련-문서) · [기능 요구사항](01-func/01-requirements.md#경기도-지역-선택-지도) · [기술 구조](03-tech/01-architecture.md#경기도-지역-선택-지도)

2026-11-20(Asia/Seoul)에 작성한 `frontend` 브랜치의 착수 계획이다. 이 문서는 작업 순서와 대기 사유를 관리하며, 기능 정책과 데이터 처리 기준은 위 명세를 원본으로 사용한다.

## 현재 상태와 이번 목표

| 구분 | 내용 |
| --- | --- |
| 현재 구현 | 경기도 31개 시·군 지도와 선택 도시 관광지 패널을 연결했다. 시흥 20곳의 상세·담기를 제공하고 미등록 지역은 준비 중으로 안내한다. |
| 확정한 방향 | 관광 대상 지역은 경기도다. 이번 작업에서는 탐색 화면에 시·군을 선택하는 지도를 추가한다. |
| 이번 산출물 | 상단 왼쪽 약 2/3의 지도와 오른쪽 약 1/3의 선택 도시 관광지 목록을 제공한다. 지역 선택과 관광지 상세·담기를 연결한다. |
| 후속 작업 | 다른 시·군 관광지 확보, 추천·날씨 연계와 전체 영어 화면은 별도 이슈로 진행한다. |

## 구현 순서

1. **경계 자료를 확보하고 검토한다.**
   - 기술 구조의 후보 제공처에서 원본 파일과 이용 조건을 확인한다.
   - 자료 기준일과 경기도 행정구역 현황을 대조하고, 일반구를 시 단위로 묶는 대응표를 만든다.
   - 도 전체 형태와 각 시·군의 경계·식별자·자료 출처를 검토한 뒤 SVG 데이터를 생성한다.
2. **지역 선택 컴포넌트를 만든다.**
   - 경계 데이터와 화면을 분리하고, 같은 선택 콜백을 지도와 지역 목록에 연결한다.
   - 기본·마우스 올림·키보드 초점·선택 상태를 구분하고 작은 영역도 목록으로 선택하게 한다.
3. **기존 탐색 화면에 연결한다.**
   - 경기도 지도와 선택 도시 관광지 목록을 2:1로 배치하고 기존 시흥 소개·작업 선택·배너·카탈로그를 아래로 옮긴다.
   - 상위 화면에서 선택 상태를 유지하고 전체 보기로 해제한다. 다른 탐색 탭을 오갔다 돌아와도 선택을 유지한다.
   - 관광지의 시·군 식별자로 오른쪽 목록을 필터링하고, 현재 시흥 자료와 다른 시·군의 준비 상태를 구분해 표시한다.
4. **조작과 기존 기능을 검증한다.**
   - 아래 검증 항목과 루트 README의 검사를 실행한다.
   - 결과와 증거는 [테스트 명세](04-test/01-verification.md#최신-판정)에 최신 판정으로 기록한다.

## 검증 계획

- 지역 식별자의 중복·누락, 시·군 목록과 경계 경로의 대응, SVG 좌표의 유효성을 확인한다.
- 서로 다른 시와 군을 선택하고 선택 교체·전체 보기·선택 유지가 동작하는지 확인한다. 마우스 올림만으로 확정 선택이 바뀌지 않아야 한다.
- 지도와 지역 목록을 클릭·터치·키보드로 이용하고 선택 안내, 포커스 표시와 접근 가능한 지역 이름을 확인한다.
- 관광 정보가 없는 지역의 준비 중 안내와 기존 시흥 자료의 표시 범위를 확인한다.
- 390px 모바일과 1365px 데스크톱에서 지도 비율·라벨 겹침·영역 선택·가로 넘침을 확인한다.
- 기존 장소 상세·여행 담기·저장·코스 지도와 시흥 권역 필터가 유지되는지 확인한다.
- 실행 명령은 [루트 README의 테스트 안내](../README.md#테스트)를 따른다. 문서 단계에서는 문서 검사와 공백 검사만 실행하고, 지도 구현 완료나 화면 검증 통과로 기록하지 않는다.
