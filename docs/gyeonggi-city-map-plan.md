# 경기도 시·군 선택 지도 작업 계획

[문서 안내](../README.md#관련-문서) · [요구사항](01-func/01-requirements.md#경기도-지역-선택-지도) · [기술 구조](03-tech/01-architecture.md#경기도-지역-선택-지도)

## 현재 상태와 후속 목표

- **현재 구현**: 경기도 31개 시·군 SVG 지도와 선택 도시 관광지 목록(2:1 배치), 기존 시흥 20곳과 TourAPI 수집 자료의 상세·담기 연동, 경기도 전체·31개 시·군 날씨 조회를 완료했다.
- **후속 목표**: AI 추천의 시·군 단위 연계와 해외 관광객용 영어 화면은 별도 작업으로 진행한다.
- **검증 현황**: [최신 판정](04-test/01-verification.md#최신-판정)에서 단위·데이터 정합성 결과와 실브라우저 미확인 항목을 관리한다.

## 대기 항목과 재개 조건

| 항목 | 대기 이유 | 재개 조건 |
| --- | --- | --- |
| 관광 자료 운영 검토 | 전 시·군 자료를 연결했으나 운영·요금·예약은 미확인 상태다. | 공식 안내와 사진 라이선스를 검토하고 필요 시 `npm run data:tourapi`로 갱신한다. |
| 시·군 단위 서버 연계 | 기존 `region` 계약은 시흥 내부 권역 기준이다. | 시·군 식별자·응답 계약을 확정한 뒤 API와 OpenAPI를 함께 변경한다. |
| 실브라우저 회귀 검증 | 자동 브라우저 로컬 접속 시간 초과로 390px·1365px 전체 조작을 미완료했다. | 로컬 또는 배포 서버에서 키보드·초점·상세·담기·탭 복귀를 실확인한다. |
