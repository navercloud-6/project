# 디자인 기준 — 경기 하루이음

[문서 안내](../../README.md#문서-분류-기준) · [주요 화면](../../README.md#주요-화면)

## 시각 방향과 토큰

토큰은 [globals.css](../../app/globals.css)에서 관리한다. 한국어 시스템 고딕(외부 폰트 미요청)·왼쪽 정렬·최소 12px을 유지하고, 밝은 바탕 위 흰 패널로 위계를 나눈다. 주요 버튼·활성 표면은 WCAG AA(4.5:1+) 대비의 브랜드 그래디언트(`#02823A → #027974`, `.primary`), 보조·취소 버튼은 흰 테두리(`.secondary`)를 사용한다.

## UX 라이팅 기준

- 대화형 안내·제목·버튼은 해요체(`~해요`, `~해 주세요`)로, 출처·정책·검토 전 고지는 간결한 안내형(`~합니다`)으로 구분한다.
- 영문 장식 라벨 대신 한국어 배지·제목을 쓰며 핵심 문구(`여행에 담기` ↔ `담기 취소`, `담은 여행 확인`, `여행 저장`, `장소 찾기`, `AI 검색·추천`)를 통일한다.

## 화면 구성과 조작

건너뛰기 링크 → 헤더 → 상단 고정 알림(`alert`·`aria-live`) → 탭 본문 → 푸터 → 하단 내비게이션 순으로 배치한다([기능 정책](../01-func/01-requirements.md#핵심-기능-요구사항)).

| 화면 | 배치 |
| --- | --- |
| 경기 둘러보기 | 제목 → AI 검색·추천 → 지도·도시 목록(2:1, 모바일 세로) → 작업 전환(`장소 찾기`·`담은 여행`) → 카탈로그 또는 여행 편집(`담은 여행` 시 검색·지도 접힘). |
| 경기 날씨 | 시·군 선택 → 현재 날씨·외출 가이드 → 옷차림 → 5일 예보 → 추천 장소·둘러보기 이동. |
| 여행 도우미 | 제목·지도(현재 날씨 포함) → 안전 안내 → 통합 안내·음성 → 옷차림 → 추천 명소 → 맛집. |
| 내 여행 | 첫 장소 표지·진행 상태·보관 안내·기록 모달·접이식 코스 지도·여행 수정·번역. |
| 프로필 | 여행 요약 → 선호 지역·취향 저장 → 네이버 계정·보관 안내. |

- **카드·상세**: 카드는 큰 사진·2줄 요약(760px 이하 1열, 18곳 점진 노출)을 표시하고 상세 모달은 진입 경로와 무관하게 사진·설명·주소·출처·담기 순서를 유지한다. 관광지 사진이 없거나 로딩에 실패하면 해당 화면의 기존 기본 아이콘·안내로 대체하며 사진 영역의 크기를 유지한다.
- **AI 검색**: 제목·결과 수, 44px 검색 도구, 빠른 테마만 두고 기술 설명은 생략한다(모바일은 지역·실행 버튼 병렬, 테마 가로 스크롤). 결과 목록은 상세 클릭과 담기 버튼을 분리한다.
- **지도 날씨**: 데스크톱은 우측 상단에 세로 배치하고, 760px 이하에서는 제목 아래의 가로형 요약으로 배치해 지도를 가리지 않는다. 지역·기온·상태·기준 시각·시연 표시와 오류 재시도를 유지하며, 북쪽 화살표는 하단에 둔다.
- **전환 안내**: 상세에서 담은 뒤 `담기 취소`·`담은 여행 확인`을 제공하고, 추천 적용 전 기존 담은 장소가 있을 때만 교체를 알린다.

## 접근성과 내비게이션

- 사진·AI 일기·번역·음성은 접이식 보조 기능으로 두고, 상세·기록 모달은 `dialog`(닫기·Esc·바깥 클릭·초점 복귀)로 구현한다.
- 오류·알림은 상단에 고정 노출하고 빈 목록·상한·오류에서 다음 행동으로 연결한다. 담은 장소가 있으면 하단 위 바로가기를, `담은 여행`에서는 순서 이동(`↑`·`↓`)과 전체 비우기를 제공한다.
- 탭 전환 시 본문 초점 이동·키보드 포커스·`prefers-reduced-motion: reduce`를 지원한다. 하단 캡슐 메뉴는 `aria-current="page"`·내 여행 건수를 표시하고 선택된 `경기 둘러보기` 재클릭 시 기본 탐색으로 복귀한다.
