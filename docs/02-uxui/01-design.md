# 디자인 기준 — 경기 하루이음

[문서 안내](../../README.md#문서-분류-기준) · [주요 화면](../../README.md#주요-화면)

## 시각 방향과 토큰

색상·글꼴·크기·간격·반응형 토큰은 [globals.css](../../app/globals.css)에서 관리한다. 한국어 시스템 고딕을 쓰고 외부 폰트는 요청하지 않는다. 메인 브랜드 색상(`--brand`, `#03C75A`)과 그래디언트 보조 색상(`--brand-accent`, `#04D1C9`)을 조합한 브랜드 그래디언트(`--brand-gradient`)를 주요 버튼·강조 표면에 적용하고, 밝은 바탕 위 텍스트 가독성(`--brand-ink`), 짙은 보조 톤(`--brand-deep`), 연한 바탕(`--brand-soft`, `--brand-gradient-soft`)으로 통일한다. 밝은 바탕(`--paper`) 위 흰 패널(`--surface`, `--radius-panel`, `--shadow-surface`)로 위계를 맞추며, 상태 색(`--success-*`, `--danger-*`, `--focus`)과 보조 바탕(`--surface-subtle`)을 토큰으로 공유한다. 한국어 본문은 왼쪽 정렬하고 최소 12px 이상 가독성을 유지한다.

## UX 라이팅 기준

- 대화형 안내·제목·버튼은 친근하고 명확한 해요체(`~해요`, `~해 보세요`, `~해 주세요`)로 통일하고, 출처·정책·검토 전 고지만 간결한 안내형(`~합니다` 또는 요약 문구)으로 구분한다.
- 불필요한 영문 장식 라벨 대신 한국어 배지와 제목을 사용한다.
- 핵심 행동 문구는 모든 화면에서 통일한다: `여행에 담기` ↔ `담기 취소`, `담은 여행 확인`, `여행 저장`, `장소 찾기`, `AI 검색·추천`.

## 화면 구성과 조작

건너뛰기 링크 → 헤더 → 화면 상단 고정 알림(`alert`·`aria-live`) → 탭 본문 → 푸터 → 하단 내비게이션 순으로 배치한다. 각 화면은 하나의 핵심 태스크에 집중하며, 작업 전환은 해당 작업 영역 바로 위에 둔다. 기능 정책은 [요구사항](../01-func/01-requirements.md#핵심-기능-요구사항)을 따른다.

| 화면 | 배치 |
| --- | --- |
| 경기 둘러보기 | 제목 아래에 AI 검색·추천과 경기도 지도·선택 도시 관광지 목록(2:1, 모바일 세로)을 배치한다. 지도 아래의 작업 전환(`장소 찾기`·`담은 여행`)으로 전체 검색 카탈로그와 여행 편집 중 하나를 표시한다. 여행 편집 중에는 검색·지도를 접는다. |
| 경기 날씨 | 경기도 전체·31개 시·군 선택 → 현재 날씨·외출 가이드 → 5일 예보 → 추천 장소와 해당 지역 둘러보기 이동 순으로 배치한다. |
| 여행 도우미 | 상단 작업 전환으로 관광 안내(지역별 묶음 선택·질문·대화 초기화·출처·장소 상세)와 행사 등록(포스터 입력·장소 검색 선택·일정 저장 후 내 여행 이동) 중 하나에 집중한다. |
| 내 여행 | 첫 장소 사진 표지(없으면 이름 중심)와 여행 요약·방문 진행 상태, 보관 안내, 기록 모달, 접이식 코스 지도·여행 수정·여행 번역을 분리해 제공한다. |
| 프로필 | 여행 요약·다음 행동 → 선호 지역·취향 저장·추천 이동 → 네이버 계정·보관 안내 순으로 배치한다. |

- 장소 카드는 큰 사진·두 줄 요약을 우선하고(760px 이하 1열), 전체 설명과 출처·크롭 안내는 상세와 여행 표지에 표시한다. 카탈로그는 18곳씩 점진적으로 펼쳐 긴 목록 과부하를 방지한다.
- AI 검색 패널은 작은 제목·결과 수, 44px 높이 검색 도구, 빠른 테마 순서로 구성한다. 모바일에서는 입력 아래에 지역 선택·실행 버튼을 나란히 두고 테마는 가로 스크롤한다. 제공된 NAVER Cloud 서비스 아이콘 자료의 CLOVA Studio·Cloud Search 원본을 장식 아이콘으로 사용하고 서비스·모델 나열과 반복 설명은 생략한다.
- AI 검색 결과는 검색창과 같은 폭의 흰 패널에 장소명·지역·라벨 중심의 목록을 표시한다. 미리보기와 최종 추천은 각각 최대 3곳으로 제한하고, 전체 조건 일치 수와 추천 수를 구분한다. 추천 패널에 추가 연관 목록을 붙이지 않고 전체 검색 결과로 연결한다. 추천 목록에는 순서와 추천 이유를 덧붙이고, 장소 항목을 누르면 기존 카드의 `장소 상세`와 같은 모달을 연다. 담기 버튼은 항목 클릭과 분리하고, 모바일에서는 행 아래 오른쪽에 배치해 글자가 줄바꿈하지 않게 한다.
- 장소 상세는 진입 경로와 무관하게 상단 사진 영역·설명·주소·출처·담기를 같은 순서로 표시한다. 등록된 사진이 없으면 같은 크기의 안내 영역을 표시하고 다른 장소 사진으로 대신하지 않는다.
- 지도 우측 상단 날씨는 지역명·아이콘·기온 순으로 세로 배치하고 상태·기준 시각을 안내한다. 공급자 링크·모델·대표 지점 설명은 카드에서 생략하고 시연 모드에만 `예시 날씨`를 표시한다. 북쪽 화살표는 하단 지역 선택 도구 위에 둔다. 도시 미선택 상태에서는 대표 시·군 칩과 지도·목록 선택 안내를 함께 제공한다.
- 날씨 탭의 시·군 선택은 지도와 공유하며 도시 전환 중에는 로딩 안내를 표시한다. 조회 실패 시 오류와 재시도를 제공하고 이전 도시의 자료는 표시하지 않는다.
- 주요 버튼은 `#03C75A → #04D1C9` 브랜드 그래디언트(`.primary`), 보조·취소 버튼은 흰 테두리(`.secondary`)를 사용한다. 상세 모달에서 담은 뒤에는 `담기 취소`를 보조 버튼으로 두고 `담은 여행 확인` 주요 버튼으로 이어 준다. 추천 적용 전 기존 담은 장소가 있을 때만 교체를 알린다.

## 접근성과 내비게이션

- 방문 사진·AI 일기, 번역·음성은 접이식 보조 기능으로 두고 상세·기록 모달은 `dialog`로 닫기·Esc·바깥 클릭과 초점 복귀를 지원한다.
- 모든 오류·알림은 스크롤 위치와 무관하게 상단에 노출하며, 8곳 상한 알림·빈 목록·연결 오류·포스터 미등록 장소·날씨 권역 이동에서도 막다른 흐름 없이 다음 행동으로 연결한다.
- 담은 장소가 있으면 하단 메뉴 위 바로가기를 표시하고, `담은 여행`에서는 위·아래 순서 이동(`↑`·`↓`)과 전체 비우기를 제공한다.
- 화면 전환 시 본문으로 초점을 옮기며 키보드 포커스 표시와 `prefers-reduced-motion: reduce`를 지원한다. 하단 고정 캡슐 메뉴는 선택 탭의 `aria-current="page"`와 내 여행 건수를 표시하며, 이미 선택된 `경기 둘러보기`를 다시 누르면 기본 탐색으로 복귀한다.
