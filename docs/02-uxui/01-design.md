# 디자인 기준 — 경기 하루이음

[문서 안내](../../README.md#문서-분류-기준) · [주요 화면](../../README.md#주요-화면)

## 시각 방향과 토큰

색상·글꼴·크기·간격·반응형 토큰은 [globals.css](../../app/globals.css)에서 관리한다. 한국어 시스템 고딕을 쓰고 외부 폰트는 요청하지 않는다. 바다색 주요 버튼과 관광 사진으로 정체성을 드러내며, 밝은 회색 바탕 위 흰 패널로 위계를 구분한다. 한국어 본문은 왼쪽 정렬하고 장식용 통계는 배제한다.

## 화면 구성과 조작

건너뛰기 링크 → 헤더 → 상태 메시지(`alert`·`aria-live`) → 탭 본문 → 푸터 → 하단 내비게이션 순으로 배치한다. 기능 정책은 [요구사항](../01-func/01-requirements.md#핵심-기능-요구사항)을 따른다.

| 화면 | 배치 |
| --- | --- |
| 경기 둘러보기 | 상단에 경기도 지도·선택 도시 관광지 목록(2:1, 모바일 세로)을 두고 아래에 소개·작업 전환(장소 찾기·추천받기·담은 여행)·배너·카탈로그를 배치한다. |
| 내 여행 | 첫 장소 사진 표지(없으면 이름 중심)와 여행 요약, 보관 안내, 기록 모달, 접이식 코스 지도·여행 수정·여행 번역을 분리해 제공한다. |
| 여행 도우미 | 관광 안내(질문·출처·장소 상세)와 행사 등록(포스터 입력·일정 저장 후 내 여행 이동) 중 하나를 선택한다. |
| 경기 날씨 | 권역 선택 → 현재 날씨·외출 가이드 → 5일 예보 → 추천 장소와 권역 탐색 이동 순으로 배치한다. |
| 마이 | 여행 요약·이동 → 선호 지역·취향 저장·추천 이동 → 네이버 계정·보관 안내 순으로 배치한다. |

- 장소 카드는 큰 사진·두 줄 요약을 우선하고(760px 이하 1열), 전체 설명과 출처·크롭 안내는 상세와 여행 표지에 표시한다.
- 지도 우측 상단 날씨는 아이콘 위·기온 아래 세로 배치에 예시 표기를 두고, 북쪽 화살표는 하단 지역 선택 도구 위에 둔다.
- 주요 버튼은 바다색, 보조 버튼은 흰 테두리를 사용하며 `여행에 담기`·`담기 취소`·`여행 저장` 문구와 진행 상태를 명확히 표시한다. 추천 적용 전 기존 담은 장소 교체를 알린다.

## 접근성과 내비게이션

- 방문 사진·AI 일기, 번역·음성은 접이식 보조 기능으로 두고 상세·기록 모달은 `dialog`로 닫기·Esc·바깥 클릭과 초점 복귀를 지원한다.
- 담은 장소가 있으면 하단 메뉴 위 바로가기를 표시하고, 빈 목록·8곳 상한·연결 오류에서도 다음 행동으로 연결한다.
- 화면 전환 시 본문으로 초점을 옮기며 키보드 포커스 표시와 `prefers-reduced-motion: reduce`를 지원한다. 하단 고정 캡슐 메뉴는 선택 탭의 `aria-current="page"`와 내 여행 건수를 표시한다.
