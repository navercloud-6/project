# 디자인 기준 — 시흥 하루이음

[문서 안내](../../README.md#문서-분류-기준) · [주요 화면](../../README.md#주요-화면)

## 시각 방향과 토큰

색상·글꼴·크기·간격·반응형 값은 [globals.css](../../app/globals.css)에서 관리한다. 한국어 시스템 고딕을 사용하고 외부 폰트는 요청하지 않는다.

바다색 주요 버튼과 실제 관광 사진으로 정체성을 드러낸다. 밝은 회색 바탕 위 흰 패널을 두고, 일관된 여백·모서리와 얕은 그림자로 위계를 구분한다. 한국어 본문은 왼쪽에 정렬하고 주소·출처를 우선하며 장식용 통계는 배제한다.

## 화면 구성과 조작

건너뛰기 링크 → 헤더 → 상태 메시지(`alert`·`aria-live`) → 탭 본문 → 푸터 → 하단 내비게이션 순서로 배치한다. 기능·제한은 [요구사항](../01-func/01-requirements.md#핵심-기능-요구사항)을 따른다.

| 화면 | 배치 |
| --- | --- |
| 시흥 둘러보기 | 장소 찾기·추천받기·담은 여행을 분리한다. 장소 찾기를 기본으로 열고, 추천 결과와 담은 목록에서도 장소 상세를 바로 확인한다. 담은 여행에서 순서·이름·날짜를 정해 저장한다. |
| 내 여행 | 첫 장소의 사진 표지와 이름·날짜·장소 수·기록 수를 패스 그리드에 표시한다. 사진이 없으면 이름 중심 표지를 사용한다. 계정 연결 상태에 맞는 보관 안내와 기록 모달, 접이식 코스 지도·여행 수정·여행 번역 패널을 작업별로 분리해 제공한다. |
| 여행 도우미 | 관광 안내와 행사 등록 중 한 작업을 선택한다. 관광 안내는 추천 질문과 출처·장소 상세를 연결하고, 행사 등록은 포스터 자동 입력과 일정 확인·저장을 구분해 저장 후 내 여행으로 이동한다. |
| 시흥 날씨 | 권역 선택 → 현재 날씨·외출 가이드 → 5일 예보 → 추천 장소와 권역 탐색 이동 순서로 배치한다. |
| 마이 | 여행 요약·이동 → 선호 지역·활동 취향 저장·추천 이동 → 네이버 계정·여행 보관 안내 순서로 배치한다. |

장소 찾기는 큰 사진과 검색을 우선하고 카드 설명은 두 줄로 요약한다. 전체 설명과 자료·사진 출처는 상세에서 제공한다. 여행 표지에도 사진 저작자·라이선스·크롭 안내를 표시한다. 추천 입력·담은 여행·도우미·마이는 단일 열로 집중시키고 담은 목록에는 순서·사진·장소명을 함께 표시한다. 760px 이하에서는 장소 카드를 1열로 표시한다. 마이의 집계는 숫자·단위·이동 버튼의 위계를 구분한다.

경기도 확장에서는 장소 찾기 맨 위에 왼쪽 지도·오른쪽 선택 도시 관광지 목록을 2:1 비율로 배치한다. 오른쪽 목록은 사진·장소명·짧은 설명·상세 보기·여행 담기를 제공하고 긴 목록은 패널 안에서 스크롤한다. 좁은 화면에서는 지도와 목록을 세로로 배치한다. 기존 시흥 소개·작업 선택·배너·카탈로그는 지도 영역 다음에 둔다. 지도 선택 동작과 빈 지역 안내는 [지도 요구사항](../01-func/01-requirements.md#경기도-지역-선택-지도)을 따른다.

지도 오른쪽 상단의 날씨는 아이콘 위·기온 아래의 세로 배치로 표시하고 작은 예시 표기로 실제 관측값과 구분한다. 북쪽 화살표는 지도 하단의 지역 선택 도구 위에 배치한다.

버튼은 주요 행동에 바다색, 보조 행동에 흰색 테두리를 사용하고 진행 중인 작업은 구체적인 상태 문구로 표시한다. 장소 선택은 `여행에 담기`·`담기 취소`, 저장은 `여행 저장`으로 통일한다. 추천 적용 시 기존 담은 장소를 교체한다는 사실을 버튼 앞에서 알린다.

## 접근성과 내비게이션

- 방문 기록은 만족도·메모 저장을 우선하고 사진·AI 일기는 접이식 보조 기능으로 둔다. 장소 상세의 번역·음성도 접어서 제공한다.
- 상세·기록 모달은 `dialog`와 배경 음영을 사용한다. 닫기 버튼·Esc·바깥 클릭으로 닫고 이전 초점으로 돌아간다.
- 담은 장소가 있으면 하단 메뉴 위에서 여행 확인으로 바로 이동한다. 날씨·상세에서도 같은 구성으로 이어진다. 빈 목록은 장소 찾기와 추천받기로, 8곳 상한 도달은 담은 여행 정리로, 세션·날씨 실패는 다시 시도로 연결해 막다른 흐름을 두지 않는다. 방문 기록 오류는 모달 안에 표시한다.
- 화면 전환 시 본문으로 초점을 옮기고, 브랜드를 눌러도 작성 중인 여행을 유지한다.
- 키보드 포커스를 표시하고 `prefers-reduced-motion: reduce`에서는 스크롤·전환 효과를 끈다.
- 다섯 탭을 하단 고정 캡슐 메뉴로 제공한다. 선택 탭에 배경·글자색과 `aria-current="page"`, 내 여행에 저장 건수를 표시한다. 안전 영역과 본문 하단 여백을 확보한다.
